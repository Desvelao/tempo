## [0.1.0] - 2026-11-14

First release.

### Added
- 13 brain-training mini-games across five skills: Memory (Grid recall, Pair match), Attention (Stroop,
  Odd one out, Mental rotation), Speed (Quick math, Reaction tap, Visual search), Working memory (N-back,
  Reverse sequence, Digit span) and Flexibility (Rule switch, Trail alternate).
- Daily sessions that play each skill once, with per-skill adaptive difficulty. Choose random games, adaptive
  (favours weaker and less recently played skills), any of your lists, or one specific list.
- Free play of any single game, and custom game lists (optionally shuffled each run).
- Streak, weekly strip, progress charts per skill, and insights: strongest and weakest skill, best time of day,
  this week versus last week, and personal bests.
- Optional local daily reminder at a time you choose.
- Sound effects, ambient music and haptics, each switchable.
- Dark "Focus" theme (default), a light theme and a colour-blind-friendly palette, plus a reduced-motion option.
- Export and import of settings, game lists and progress as a backup file, and options to reset settings or
  delete lists, progress or everything.
- Get started introduction, an About dialog with the project link, and a cadence-ring launcher icon with a
  themed-icon version.
- English and Spanish translations.
- Each GitHub Release includes a `SHA256SUMS` file, and the README explains how to verify a download.
- Fully offline: no internet permission, analytics or ads. Your results never leave the device.
